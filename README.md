# USTIVO

**Telegram Mini App для поиска услуг и мастеров в Узбекистане 🇺🇿**

---

## 🚀 О проекте

USTIVO — это платформа, которая объединяет клиентов и исполнителей услуг прямо внутри Telegram.

Пользователи могут быстро находить мастеров, а специалисты — получать заказы без посредников.

Работает по всему Узбекистану, включая Ташкент и регионы.

---

## 🔍 Возможности

- Поиск мастеров по категориям
- Поиск по городу
- Геолокация и расстояние до исполнителя
- Просмотр объявлений с фото и описанием
- Прямой контакт с мастером
- Публикация собственных услуг
- Работа прямо внутри Telegram Mini App

---

## 🧩 Как это работает

1. Открой Telegram Mini App
2. Выбери услугу или введи запрос
3. Найди подходящего мастера
4. Свяжись напрямую без посредников

---

## 🛠 Для мастеров

- Добавление объявлений с фото и описанием
- Выбор категории и города
- Получение заявок напрямую от клиентов
- Управление своими объявлениями

---

## 📍 География

USTIVO работает по всему Узбекистану:
- Ташкент
- Области и регионы
- Локальный поиск по городу и району
