# USTIVO

USTIVO — Telegram Mini App for services in Uzbekistan 🇺🇿

## О проекте

USTIVO помогает людям находить мастеров и услуги:
- сантехники
- электрики
- ремонт
- уборка
- и другие бытовые услуги

Все работает прямо внутри Telegram Mini App.

## Возможности

- поиск услуг по категориям
- поиск по городу
- прямой контакт с мастером
- публикация объявлений
- бесплатный старт для пользователей
