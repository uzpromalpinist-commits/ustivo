# USTIVO Roadmap

## Текущее состояние ustivo
- Telegram Mini App полностью работает
- Система объявлений запущена
- Категории услуг реализованы
- Поиск по услугам работает
- Геолокация уже используется для показа расстояния до мастеров
- Сервис работает по всему Узбекистану

## Основная цель продукта
Сделать удобный сервис для поиска мастеров и бытовых услуг через Telegram.

## Дальнейшее развитие

### 1. Улучшение платформы
- Оптимизация поиска и фильтров
- Улучшение скорости загрузки
- Улучшение UX мобильной версии

### 2. Расширение функционала
- Добавление новых категорий услуг
- Улучшение карточек объявлений
- Улучшение системы публикации объявлений

### 3. Масштабирование
- Рост количества пользователей
- Расширение базы мастеров по регионам Узбекистана
- Усиление присутствия в Telegram

## Фокус проекта
Простота, скорость и удобство поиска услуг внутри Telegram.
