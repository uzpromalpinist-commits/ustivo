# USTIVO — Как пользоваться

## 1. Первый запуск
- Открой USTIVO в Telegram
- Вход происходит автоматически через Telegram
- Новым пользователям начисляется приветственный бонус

## 2. Главная страница
- Есть поиск услуг
- Можно выбрать город
- Можно использовать геолокацию
- Объявления загружаются при прокрутке

## 3. Как найти мастера
- Введите услугу или профессию
- Выберите город (если нужно)
- Откройте объявление
- Посмотрите контакты и описание

## 4. Как создать объявление
- Нажмите кнопку "+"
- Добавьте фото
- Укажите заголовок
- Выберите категорию
- Добавьте описание
- Укажите город и контакты
- Нажмите "Опубликовать"

## 5. Лимиты
- Первое объявление бесплатно
- Дополнительные публикации ограничены системой лимитов

## 6. Баланс
- Пополнение через профиль
- Подтверждение вручную
- После проверки баланс зачисляется

## 7. Поддержка
- Через Telegram внутри приложения
